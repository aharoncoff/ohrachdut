# Ohr Achdut Website

Minimal dark-theme React/Vite website for Ohr Achdut in Phoenix, Arizona.

## Local setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare Pages settings

- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
